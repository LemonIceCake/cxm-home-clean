# C × M HOME

繁體中文居家財務與採購網站，金額為新臺幣。原有 Excel 完整保留，沒有讀取或匯入其私密內容。零前端套件依賴，Node.js 20+。

## 本機使用

在本資料夾執行 `node server.mjs`，開啟 http://127.0.0.1:5173 。執行 `node --test tests/*.test.mjs` 驗證計算。

尚未設定雲端可進入獨立示範模式，變更只在記憶體，重新整理即消失。正式資料預設全空。不使用 localStorage、Excel 或假同步。正式登入的 token 也只在記憶體；重新整理需重新登入。

## 最少雲端設定（Supabase）

1. 建立 Supabase 專案，在 SQL Editor 執行 `supabase.sql`。
2. Authentication 建立兩個使用者（由 Dashboard 建立並確認 email），關閉公開註冊。記下兩人的 user UUID。密碼請自行設定，不要寫入原始碼。
3. 在此專案執行 `node bootstrap.mjs`，產生空白家庭建立 SQL（不含使用者或真實財務資料）。於 SQL Editor 執行，取得家庭 UUID，再執行：

```sql
insert into public.household_members(household_id,user_id) values
('家庭 UUID','第一位使用者 UUID'),('家庭 UUID','第二位使用者 UUID');
```

4. 複製 `config.example.js` 為 `config.js`，填入專案 URL 與公開 publishable/anon key。**不可放 service_role、私密金鑰或資料庫密碼**。`config.js` 已忽略 Git；設定完成重新整理即可登入。

資料模型：households 保存 schema=1 的家庭文件、版本與更新時間；household_members 限制最多兩人且每帳號僅一家庭。文件包含 items、六類 budgets、house、mortgages。品項內含比價與付款陣列，退款用負數。各項編輯均透過 save_household RPC 以 expected_version 原子檢查；RLS 僅成員可讀，瀏覽器沒有直接寫入或建立家庭／成員權限。每 5 秒讀取新版本，編輯期間版本改變會拒絕儲存，避免靜默覆盖。衝突請匯出保留輸入、載入最新版本再人工合併。儲存失敗保留本次頁面的输入，可重試；關閉頁面前請匯出。

## 操作與計算

- 在購買清單新增所有商品／工程。預算頁新增入口會預選分類。可篩選搜尋、修改分類、取消、確認刪除；主要商品連結另開分頁。
- 待比較預設不納入、已選定預設納入；訂購／到貨沿用。未知單價為待估價。已含安裝則額外費用填零；整包工程內含設備放備註，不另外新增占預算。
- 單筆成本＝單價×數量＋整筆費用－折扣；付款不重複扣預算。取消仍保留付款，退款在該筆輸入負數；超付提示處理，其他訂單餘額不互相抵扣。
- 各類可編輯上限與貸款，關閉時不計本金與月付。房屋總價與分類總預算各計一次，貸款只當資金來源。實際核貸分配不符需求會提示；允許先儲存其中一筆再補第二筆。
- 本息平均攤還，寬限包含於總年限。當期正常付款後執行額外本金。寬限期縮短年限以原本金在原寬限期結束後的月付為基準；降低月付依當期餘額與原剩餘攤還期重算。最後一期不超過本金＋利息。內部保留浮點精度，顯示四捨五入至元，合併以同年、連續月份、四捨五入月付相同判斷，額外本金逐月另列。總覽先合併同年月所有貸款，再合併期間。
- 金額不包含未另列的稅費、保險及銀行手續費；此為固定輸入利率的試算。日期使用台灣時區。
- JSON 備份包含私密財務資料，請自行安全保存。正式模式拒絕示範備份。還原前應匯出目前資料。

## 驗證與限制

測試涵蓋成本、分次付款／退款、取消、超支、待估價、分類移轉、超付隔離、零利率／零貸款、寬限、多次提前還款兩種方式、最後一期、不同起始年月合計與年度分列。沒有 Supabase 憑證前，雲端登入、RLS 實際阻擋與兩台裝置同步尚未實測。

雲端驗收：兩位授權帳號分別登入，新增／修改後另一端 5 秒內更新；同時編輯應提示衝突。再用第三個帳號與未登入 REST 請求確認無法讀取及 RPC 寫入。測试斷網後儲存，輸入應保留且可重試。採用整份家庭文件版本鎖，不同品項同時儲存也可能提示衝突，是保守避免覆蓋的取捨。

## 青安 3.0 更新（2026-10-13）

新青安頁面提供青安 3.0 五階段模式與自訂固定利率模式。舊資料未設定模式時，以開始還款年月作為暫定撥貸年月套用 3.0 試算，不改動雲端原始資料；請在編輯中確認實際撥貸年月，儲存後將模式、撥貸年月、各階段利率寫入既有家庭文件。不需要再執行 SQL，JSON schema=1 與舊備份相容。

五階段利率預設 1.775／1.9／2.025／2.15／2.275%，以基準利率 1.72% 不變推估，實際輸入可修改。利率期間依撥貸滿 36／48／60／72 月切換，與寬限期分開。採年月近似，不處理銀行首期畸零天數或按日補貼切換。銀行實際帳單仍優先。

利率切換時，寬限期按剩餘本金計息；攤還期依剩餘本金與剩餘期數重算。縮短年限的提前還款維持當時月付，計算縮短後到期月；後續利率變更依縮短後到期月重算月付。若後來採降低月付，回復原到期月。寬限期內縮短年限保留前次降低月付之後（若有）的本金基準，在寬限期結束時用當時適用利率及原攤還期數決定月付，再依提前還款後本金縮短到期月。零利率與最後一期調整皆適用。

模型新增 rateMode、disbursed、stages（offset 月數、rate 年利率）欄位。總覽仍先按曆年月合計所有貸款，然後依同年、連續月份、顯示至元相同的月付合併。逐月明細新增適用年利率。
